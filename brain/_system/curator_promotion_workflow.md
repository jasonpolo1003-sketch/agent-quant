# Curator Promotion Workflow

This is the gate between messy research and the durable second brain.

## Purpose

Research agents can collect a lot of information. The curator decides what is useful, supported, and structured enough to save permanently.

## Flow

```text
raw research brief
  -> curator review
  -> reject / needs more work / promote source
  -> source note in brain/01_Sources/
  -> optional method door update
  -> optional strategy card only if testable
```

## Promotion Rules

Promote a source only if:

- it has a title and summary
- important claims have source URL/evidence or are marked low-confidence/unverified
- risks/caveats are preserved
- possible strategy rules are separated from proven facts
- it belongs in a specific method family or stays unclassified

Do not promote if:

- it is hype with no concrete testable information
- it claims profit without evidence
- it depends on impossible data for the MVP
- it would push the project into live trading too early

## Curator Verdicts

- `promote_source`: create a durable source note
- `update_door`: update a method family door note
- `create_strategy_card`: only when rules are precise and testable
- `needs_more_work`: send back to research
- `rejected`: not useful enough

## Important

The curator does not prove a strategy works. It only decides whether information is good enough to enter the organized brain.
