# Research Brief — RQ-0000

## Research Question

What should the agent research?

## Agent Task

Find legal/public sources. Extract concrete claims, strategy rules, risks, limitations, and evidence.

## Required Output Format

```text
Source URL / citation:
Source type: paper | book | blog | repo | docs | other
Main claim:
Evidence quote or exact passage:
Possible strategy rule:
Risks / caveats:
Confidence: low | medium | high
```

## Rules

- Do not download copyrighted books illegally.
- Cite every source.
- Label uncertain claims as `unverified`.
- Save messy notes in inbox before promotion.
