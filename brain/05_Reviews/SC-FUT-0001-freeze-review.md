## Development-only prop-eval simulator specification

**Prerequisite:** only after the same strategy spec is frozen and the development-period replay is authorized. Use its L3 per-eligible-day net one-MNQ P&L and all 500 paired same-date control draws. This is a *path-risk diagnostic*, not a strategy-selection gate and not an instruction to buy an eval. Run on the locked period only if separately authorized in the held-out run protocol; never select the best size on dev and call later results independent.

- Generate complete pseudo-paths of eligible days using seeded **stationary block bootstrap, mean block five days**, preserving contiguous source sessions and zero-trade days. Use identical sampled date indices for the strategy and each paired control path; never independently resample ORB and controls. Record bootstrap seed, replicate count, source hashes, venue rules, horizon and common indices. Report Monte Carlo intervals/standard errors and dependence-length sensitivity. The 500 draws are control *paths*, not 500 independent market-day observations.
- For each of **1, 2, 3, 5 MNQ**, scale the source contract's trade-by-trade P&L/costs and path; do not assume five independently drawn returns. Check venue size cap and contractual micro equivalence. Compute account balance and, **if required by venue**, high-water mark on the specified intraday equity/balance basis. Apply daily limit and trailing drawdown at the exact times in the rulebook; define precedence when target and breach occur on the same minute. Record terminal `pass`, `blown_up`, or `time_out`. Pass probability = pass / all paths; blow-up = breach / all paths; time-out separately. Median eligible days to pass is conditional on pass, unavailable if no paths pass; also report unconditional distribution/censoring. Controls get the identical rulebook and sizing.
- **Critical identifiability limit:** *daily realized P&L alone cannot determine an intraday daily-loss breach or an unrealized-equity trailing drawdown*. Never label probabilities based solely on daily totals as exact venue-rule pass/blow-up probabilities. Prefer minute-/trade-level marked equity and adverse excursion retained by replay; if unavailable, publish only explicitly labeled end-of-day approximations plus conservative lower/upper bounds, or mark venue probabilities `not_estimable`. Zero-trade days still count if venue defines them as eligible days, but may not count toward a minimum *trading* day requirement.
- Test synthetic paths covering intraday drawdown despite positive day close, trailing high-water ratchet, daily reset, same-minute target and breach, early close, no-trade day, repeated-day blocks, missing path marks, fees/size scaling, and time-out; compare exact outcomes to hand-worked fixtures. No invented “$3,000 target” from the illustrative pasted arithmetic.
