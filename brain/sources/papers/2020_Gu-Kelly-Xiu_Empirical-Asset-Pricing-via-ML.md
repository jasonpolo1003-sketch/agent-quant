# Empirical Asset Pricing via Machine Learning (Gu, Kelly, Xiu)

**Citation:** Gu, S., Kelly, B., Xiu, D. (2020). Empirical Asset Pricing via Machine Learning. Review of Financial Studies 33(5), 2223–2273.  
**Free copy:** https://dachxiu.chicagobooth.edu/download/ML.pdf  
**Version:** Hosted on coauthor Dacheng Xiu's Chicago Booth site (published RFS PDF)

## Key points (each backed by verbatim quote)

1. **Trees and NNs best; gains from nonlinear interactions**  
   > "We identify the best-performing methods (trees and neural networks) and trace their predictive gains to allowing nonlinear predictor interactions missed by other methods." (PDF p.1)

2. **Dominant signals**  
   > "All methods agree on the same set of dominant predictive signals, a set that includes variations on momentum, liquidity, and volatility." (PDF p.1)

3. **S&P 500 timing result**  
   > "A portfolio strategy that times the S&P 500 with neural network forecasts enjoys an annualized out-of-sample Sharpe ratio of 0.77 versus the 0.51 Sharpe ratio of a buy-and-hold investor." (PDF p.2)

## Relevance to Quant Agent Brain
AI/ML benchmark for later phases. Note the S&P 500 timing figure is pre-cost and monthly; not evidence for daily RSI rules.
