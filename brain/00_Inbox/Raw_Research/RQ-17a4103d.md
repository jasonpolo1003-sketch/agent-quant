# Raw Research Note — RQ-17a4103d

## Research Question

Find high-quality sources for a simple daily ETF RSI oversold-rebound method; capture the exact RSI formula and a small defensible set of entry, exit, and maximum-holding-period choices for SPY, QQQ, and IWM, plus timing, cost, and overfitting risks. Do not claim an edge or optimize parameters.

## Scout Findings

This pass used public documentation and kept source claims separate from proposed research choices. It found enough evidence to define RSI consistently and identify two entry-condition candidates, but not enough evidence to approve an exit rule or maximum holding period.

### Source 1 — StockCharts ChartSchool: Relative Strength Index (RSI)

- Source URL: https://chartschool.stockcharts.com/table-of-contents/technical-indicators-and-overlays/technical-indicators/relative-strength-index-rsi
- Public Markdown version checked: https://chartschool.stockcharts.com/table-of-contents/technical-indicators-and-overlays/technical-indicators/relative-strength-index-rsi.md
- Source type: documentation / educational reference
- Main claim: Wilder's RSI uses relative strength based on smoothed average gains and losses and is normalized to a 0–100 oscillator.
- Exact formula captured:

```text
RSI = 100 - (100 / (1 + RS))
RS = Average Gain / Average Loss
```

- Formula details: the default calculation uses 14 periods. The first average gain/loss uses the simple 14-period average; later values use Wilder smoothing: `[(previous average × 13) + current value] / 14`.
- Threshold evidence: the page states that Wilder considered RSI above 70 overbought and below 30 oversold.
- Short-horizon alternative: the page says short-term traders sometimes use 2-period RSI with above 80 / below 20 levels.
- Important caveat: oversold conditions can persist in strong downtrends, and the page says overbought/oversold readings work best when prices move sideways within a range.
- MVP data required: adjusted daily close for SPY, QQQ, and IWM with enough warm-up history.
- Confidence: medium-high for the indicator definition; low for any claim of trading edge.

### Source 2 — TA-Lib Technical Analysis Documentation: RSI

- Source URL: https://ta-lib.github.io/ta-doc/indicator/RSI.htm
- Source type: official library documentation
- Main claim: TA-Lib documents RSI as a price oscillator ranging between 0 and 100 and links to its C/C++ `TA_RSI()` implementation.
- Useful role: implementation provenance and a future cross-check for the project's own RSI calculation.
- Limitation: this page does not establish profitable entry, exit, or holding-period rules.
- MVP data required: daily close series.
- Confidence: high for implementation provenance; low for strategy-rule evidence.
